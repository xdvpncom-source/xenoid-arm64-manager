# v0.1.46 — observe an unchanged pre-regeneration owner during membership refresh

Adding a managed device requires fresh observations from the current fleet before another native identity reservation can be admitted. A worker already waiting for that admission holds its native operation lock. Previously the periodic observer skipped every busy lock, so those waiting workers could prevent the very membership refresh needed to acknowledge them.

The host observer now permits a bounded read beside a specifically proven waiting owner. It verifies the current worker, PID/start time, service cgroup and exclusive lock ownership; its exact active request must still be an unacknowledged, unprepared reservation with no native journal or completion. The observer reads the actual native values anew and requires them to match the retained before-values. The owner, request, lock, runtime and pending state must remain unchanged after the read. Any conflicting owner or transition still produces no observation.

The existing eight-second budget, authenticated nonce, observation schema, capture timestamp and controller ledger path are retained. Old before-values are not relabelled as a fresh capture. The change does not reserve or finalize identities, write Android settings, inject input, restart workers or modify the ledger's admission rules. Normal unlocked observations retain their existing path.

Regression tests cover the real waiting-owner shape, kernel lock ownership, actual fresh values, stale request and owner changes, acknowledgement or journal arrival, runtime replacement, private-file validation and the shared read deadline. Live fleet recovery and subsequent generation results are recorded separately from source qualification.

On a live blocked reservation, the old observer skipped the busy native lock while the candidate returned a fresh observation in 2.224 seconds. The measured values matched the unchanged request baseline, and before/after identity evidence remained equal. The observation call performed no native mutation or publication. Completing fleet membership and resuming the pending generation remain separate controller steps.
