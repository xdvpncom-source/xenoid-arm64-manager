# v0.1.45 — preserve a verified cold Bluetooth baseline before regeneration

A freshly cold-seeded device can publish its valid native Bluetooth address before Android populates the optional `bluetooth_addr_valid` setting. The regeneration snapshot previously substituted a placeholder for that state. Managed identity admission then correctly rejected the difference from the actual enrolled address before reserving identities or preparing a native journal.

The snapshot now retains the existing address only when the validity flag is missing, a cold profile is configured, and the native sidecar and both published controller properties independently prove the same address. The sidecar must have its expected owner, mode, size and single-link regular-file shape; the native address-ready property must also be set. Explicit invalid flags, legacy paths, malformed or placeholder addresses, and failed proof retain their previous behavior.

This is a read-only host-Python correction. It does not initialize Bluetooth, set properties, alter current device identities, relax managed reservation checks, rebuild Android images or APKs, or change the official Xenoid touch path. Only the backend source entry changes in the existing native bundle; earlier source hashes remain accepted as upgrade inputs.

Regression coverage runs the production snapshot and proof shell, including missing and initialized flags, unverified and conflicting native surfaces, unsafe sidecar metadata and links, malformed addresses, and legacy behavior. Live first-generation and loop results are recorded separately from source tests.

On the affected live cold-seeded device, the candidate snapshot preserved the actual enrolled address while the validity flag was still unset. A controlled call through the existing official setter then republished that same address for compatibility with the already-running worker. All measured identities remained unchanged, with no worker restart, regeneration or pointer event. Subsequent normal-generation and loop observations are separate checks.
